# Chess64

This project was my Advanced Data Structures year project. It is meant to replicate Chess.com.

## Specifications

**Backend:** Laravel, PHP, WebSockets

**Frontend:** ReactJS, Inertia, TailwindCSS

**Database:** MySQL

## About

This project isn't my best work but it allowed me to learn more about web development and test out new tools I have never used before. This was my first time working with PHP, Laravel, Websockets, and Inertia. As said before, this was my year long project for Advanced Data Structures. When deciding on my project I wanted to challenge myself so I decided to use a new programming lanaguage I never used before with a framework I never used before and as my project evovled I had to implement even more tools such as websockets, and Inertia. This allowed me to learn as much as possible about web devlopmenet and the different aspects.
